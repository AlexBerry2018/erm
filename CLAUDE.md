# Рабочий стол-пинбол

Мобильная игра (Android, позже веб): плинко/пинбол-билдер с забегами по сиду. Сеттинг: ASCII-аниме-стримерша и кот на бумажном рабочем столе Win95. Полный дизайн — `docs/DESIGN.md`, стиль — `docs/STYLE.md`.

## Правила проекта (не нарушать)
- **Только альбомная ориентация.** В портрете — экран «поверни телефон».
- **Только светлая тема** (бумажный Win95). Тёмной темы нет.
- **VHS-фильтр включён по умолчанию,** выключается в настройках. Фильтр не должен ронять fps: никаких `filter:` на больших слоях, анимация только через `transform` / `opacity`.
- **APK собирать только когда пользователь прямо попросит** («собери APK»).
- **Не пушить на GitHub без просьбы.** Коммитить локально можно.
- Язык интерфейса и комментариев — русский.
- Не копировать чужие игры: названия, тексты, графику и уникальные правила Balatro / Peglin / Ballionaire.

## Стек (согласован)
- Vite + TypeScript, рендер на Canvas 2D, UI-окна — DOM поверх канваса. Шрифты — локально через `@fontsource` (без сети).
- Физика: своя (`src/physics/`): круг против прямоугольников и кругов, фиксированный шаг 1/120 с, 2 подшага. Монетки друг с другом не сталкиваются.
- Окна в раскладке только перетаскиваются (размер не меняется). Лунок 6: `+10 ×2 КОТ ×3 +10 КОРЗИНА`.
- ГСЧ только сидовый (`mulberry32` / `sfc32`), никакого `Math.random()` в игровой логике.
- Android: WebView-обёртка или Capacitor; сборка APK через GitHub Actions.

## Структура (целевая)
```
src/
  main.ts          — запуск, цикл кадра
  physics/         — монетка, столкновения, фиксированный шаг
  board/           — доска, объекты, лунки, раскладка окон
  run/             — забег, раунды, боссы, выбор 1 из 3, сид
  stream/          — камера стримерши, чат, голосования
  fx/              — частицы, тряска, хитстоп, всплывающие цифры, звук
  ui/              — окна Win95, HUD, экраны
  meta/            — слава, Студия, коллекция, сохранение
docs/              — DESIGN.md, STYLE.md
reference/         — старые прототипы, только для чтения
```

## Справочные файлы (reference/, не редактировать)
- `style-prototype-y2k.html` — чистый пример стиля: окна Win95, чат с голосованиями, ASCII-камера, кнопки, пульт. **Лучший источник CSS.**
- `crystal-2000-legacy.html` — прошлая игра (merge). Оттуда можно брать:
  - ASCII-арты стримерши и кота (эмоции, позы);
  - фразы чата;
  - звуки (`sfx`, WebAudio);
  - VHS-фильтр;
  - экран «поверни телефон».

  Сам код там многослойный, переносить только идеи и данные, не обёртки.

## Команды
- `npm run dev` — разработка, `npm run build` — сборка в `dist/`.
- `npm run sim` — бот-симуляция баланса + детерминизм (`npm run sim -- 500 targets=50,130,300,700` — проверить другие пороги).
- `npm run e2e` — Playwright по собранной игре (сначала `npm run build`), скриншоты в `tests/shots/`.

## Проверка
- После каждой фичи: `npm run build` без ошибок, игра открывается без ошибок в консоли.
- E2E на Playwright: экраны 852×393 (телефон) и 1366×768 (ПК), скриншоты, 0 ошибок консоли.
- Бот-симуляция баланса: N забегов по разным сидам → средний дошедший раунд, распределение очков. Цель: первый забег в среднем доходит до раунда 3–4.
- Детерминизм: один сид + одни и те же входы → одинаковый счёт.
