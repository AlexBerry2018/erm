# Стиль: бумажный Win95

Пример вживую — `reference/style-prototype-y2k.html`.

## Цвета
```css
:root{
  --paper:#f3efe2;   /* фон страницы — бумага */
  --paper2:#fbf8ef;  /* фон окон */
  --ink:#0a1f80;     /* основной текст — синие чернила */
  --blue:#1f44c8;    /* рамки, тени, кнопки */
  --pink:#e2245a;    /* акцент, урон, «горячее» */
  --gold:#d98a00;    /* редкость/джекпот */
  --green:#0e9f6e;   /* системные сообщения, успех */
  --grey:#d4d0c8;    /* классический серый Win95 (кнопки пульта) */
  --dim:#6b7bb8;     /* второстепенный текст */
}
```
- Редкости: обычный `--dim` · редкий `--blue` · эпический `--pink` · легендарный `--gold`.
- Фон: бумага с еле заметными горизонтальными линиями  
  `repeating-linear-gradient(0deg,rgba(31,68,200,.05) 0 1px,transparent 1px 4px)`.

## Шрифты (Google Fonts)
- `IBM Plex Mono` 400/500/700 — основной, ASCII-арт, чат.
- `Press Start 2P` — крупные заголовки, большие цифры, «ДЖЕКПОТ».
- `Roboto Condensed` — плотные подписи, где не хватает места.

## Окно
- **Рамка:** `2px solid var(--blue)`, жёсткая тень без размытия `5px 5px 0 var(--blue)`.
- **Заголовок:** градиент `linear-gradient(90deg,#000080,#1084d0)`, белый жирный моно 11px, имя вида `desktop.exe`, `chat.log`, `map.bmp`.
- **Кнопки:**
  - объёмные, рамка `border-color:#fff #404040 #404040 #fff`; при нажатии цвета рамки меняются местами;
  - главная кнопка — синяя или розовая заливка с белым текстом.
- **Фокус:** `outline:2px dashed var(--pink)`.

## ASCII
- Персонажи, частицы и иконки сделаны из символов. Набор частиц: `* + ✦ ◆ ◈ ★ ·`.
- Стримерша — ASCII-лицо в окне камеры, кот — ASCII `/\_/\`.

## Анимация
- Только `transform` и `opacity`; `prefers-reduced-motion` отключает тряску и частицы.
- **VHS:** лёгкие цветные полосы и смещение текста (`text-shadow:1px 0 rgba(255,0,80,.25),-1px 0 rgba(0,140,255,.25)`), шум — один слой, анимация через `transform`.

## Раскладка
- Альбомная ориентация, три колонки: камера+чат | игровое окно | статус+управление.
- Боковые отступы `max(16px, env(safe-area-inset-*))`.
- Зоны касания на телефоне не меньше 44 px.
